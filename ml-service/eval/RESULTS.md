## Limitations

- **The data is entirely synthetic.** It was generated by `training/generate_synthetic_dataset.py` from hand-chosen distributions, not sampled from real ReSell traffic. Real-world performance is **unvalidated**; these results must not be used as production evidence.
- The generator encodes the same signal definitions the pipelines detect (pHash bit flips, embedding-copy noise, z-score price cuts), so fraud metrics are optimistic: the pipelines were largely designed against exactly these patterns, and the v2 artifacts in `models_saved/` were themselves trained on similarly generated data.
- There is no train/test split in this harness: the saved v2 model artifacts are scored on freshly generated (but distribution-identical) samples, so there is no distribution-shift signal either.
- Vision-LLM features (`vision_llm_flag_count`, `vision_llm_confidence`) are always 0 here (no NVIDIA API key, no images in the synthetic set), and CLIP image-text similarity is passed as a provided value rather than computed from real images.
- Price comparables and the ANN index are built from the same synthetic pool being scored, so price MAE/MAPE do not reflect the sparse, noisy comparable data seen in production.
- Sample sizes (200 fraud labels, 200 sold listings) are small; metric differences of a few points are within noise.
